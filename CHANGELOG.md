## [2.0.0] - 2024-11-01

### 🎉 Major Release - Complete Restructure

#### Added
- **Modular Bootstrap System**: 12 independent installation scripts in `bootstrap/`
  - `base.sh` - Core packages and CLI tools
  - `shell.sh` - Zsh, Starship, Zellij
  - `rust.sh` - Rust toolchain
  - `python.sh` - Python (pyenv, poetry, pipx)
  - `nodejs.sh` - Node.js (nvm, pnpm)
  - `docker.sh` - Docker and container tools
  - `iac.sh` - Infrastructure as Code tools (terraform, k8s)
  - `utils.sh` - Utilities (yq, jq, glow, httpie)
  - `atuin.sh` - Advanced shell history
  - `ai.sh` - Ollama and AI models
  - `git-tools.sh` - Commitizen, pre-commit
  - `visuals.sh` - Fonts and themes

- **Devcontainer Templates**: 4 ready-to-use VS Code devcontainer configs
  - Python (3.12 + Poetry + Black + Ruff)
  - Node.js (20 LTS + pnpm + TypeScript)
  - Rust (latest + rust-analyzer)
  - Fullstack (Python + Node + Docker + PostgreSQL + Redis)

- **AI Agents**: 3 local AI agents powered by Ollama
  - `translator.sh` - Multi-language translator
  - `jira-ticket.sh` - Jira ticket generator
  - `doc-generator.sh` - Code documentation generator

- **Templates**: Document templates
  - Jira ticket template
  - ADR (Architecture Decision Record) template
  - Pre-commit hooks configuration

- **Justfile**: Advanced command runner with 40+ commands
  - Component installation commands
  - Development workflow helpers
  - Docker, Terraform, K8s shortcuts
  - AI agent wrappers

- **Documentation**:
  - Complete README rewrite (8.5kb)
  - MIGRATION.md guide
  - Proper .gitignore

#### Changed
- **Aliases**: Removed problematic aliases that break scripts
  - ❌ `grep="rg"` - Use `rg` directly
  - ❌ `find="fd"` - Use `fd` directly
  - ❌ `cat="bat"` - Use `bat` directly
  - ✅ Kept safe aliases: `ls`, `ll`, `la` → `eza`

- **Dotfiles**: Deduplicated configs between `.zshrc` and `aliases.zsh`
- **PAGER**: Changed from `bat` to `less` (standard)
- **Bootstrap**: Interactive installation with 3 modes (quick/full/custom)

#### Fixed
- Fixed tenv installation URL (was returning 404 error)
- Auto-fetch latest versions for all GitHub releases (no more hardcoded versions)
- Improved error handling in all scripts
- Added "already installed" checks to prevent reinstalls
- Fixed duplicate alias definitions

#### Removed
- Hardcoded version numbers (now auto-fetched from GitHub API)
- Duplicate alias definitions in .zshrc
- Hollywood package (problematic on some systems)
